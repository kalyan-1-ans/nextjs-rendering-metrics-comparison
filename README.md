# Next.js rendering metrics comparison

A pnpm workspace for comparing Next.js rendering approaches and performance
metrics. Currently contains only the workspace foundation, Oxlint, and TypeScript.
App frameworks remain unscaffolded.

## Setup

Use Node.js 24 LTS and pnpm 10.34.5.

```sh
pnpm install
pnpm lint
```

Use `pnpm lint:fix` to apply automatic lint fixes.
